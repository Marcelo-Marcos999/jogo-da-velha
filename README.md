# jogo-da-velha

## Project Overview

This is a simple implementation of the classic game of Tic-Tac-Toe, where a user can play against the computer. The game tracks wins, losses, and draws.

## Features

- Initialize a 3x3 empty board with numbers 1 to 9 for each position.
- User can select a position on the board to make their move, marking it with "X".
- Computer makes its move after the user's move, marking an empty position with "O".
- The game checks for a winner after each move, whether it's the user or the computer.
- The game records the outcome of each match, including wins, losses, and draws.
- User can restart the game at any time.
- The game displays statistics of wins, losses, and draws after each match.

## Technical Details

- The project is built using React 18+ with Vite and CSS Modules.
- The game is designed for a single player.
- The computer makes its moves randomly.
- The game does not include multiplayer features.

## Usage

- Clone the repository and run `npm install` to install dependencies.
- Run `npm dev` to start the development server.
- Open `http://localhost:3000` in your browser to play the game.
- Use the buttons to make your moves and restart the game as needed.
